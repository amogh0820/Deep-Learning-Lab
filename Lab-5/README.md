# Lab 5 – Handwritten Digit Recognition using RNN (LSTM)

## Aim
To build an RNN model using LSTM to recognise handwritten digits (0–9) from images.

## Dataset Used
MNIST handwritten digit dataset, containing 60,000 training images and 10,000 testing images. Each image is 28 × 28 pixels.

## Results
The LSTM model was trained for 10 epochs using the Adam optimiser and a batch size of 64. It is expected to achieve approximately 98% test accuracy. The actual accuracy is displayed after running the notebook.
